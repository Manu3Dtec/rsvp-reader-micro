Simple RSVP Reader Micro

Browser installer for the Waveshare ESP32-S3 Touch AMOLED 1.8 V2. Install the ready-to-use firmware without ESP-IDF or command-line tools.

  1. Use desktop Chrome or Edge.
  2. Connect the Waveshare ESP32-S3 Touch AMOLED 1.8 V2 by USB.
  3. Click the button and select the device's serial port.
  4. Keep the device connected until installation finishes.
Web Serial is unavailable. Open this page in desktop Chrome or Edge.

This installer is only for the 1.8-inch Touch AMOLED V2 board. Installing it on another model can leave its display or touch interface unusable until the correct firmware is restored.
